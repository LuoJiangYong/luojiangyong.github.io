## Context

This case documents the portfolio website itself. The goal is not a one-off page, but a content system that can be maintained by both the owner and future agents.

## Current scope

- Bilingual paths: `/ch/` and `/en/`.
- Content types: GitHub projects, AI Skills, cases, and blog posts.
- Visual system: warm cream canvas, serif headlines, coral accents, and dark product cards.
- Publishing: GitHub Pages with GitHub Actions.
