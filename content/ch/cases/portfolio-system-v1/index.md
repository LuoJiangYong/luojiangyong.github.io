## 背景

这个案例记录作品集网站自身的搭建过程。目标不是做一次性页面，而是建立一个后续可以由人和 agent 协作维护的内容系统。

## 当前范围

- 双语路径：`/ch/` 与 `/en/`。
- 内容类型：GitHub 项目、AI Skills、项目案例、Blog。
- 视觉系统：基于暖米色画布、serif 大标题、珊瑚色强调和深色产品展示卡片。
- 发布方式：GitHub Pages 与 GitHub Actions。
