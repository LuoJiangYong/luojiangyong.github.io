# luojiangyong.github.io

Personal portfolio site for Luo Jiangyong, built with Hugo and hosted on GitHub Pages.

Production domain: https://luojiangyong.com/

## What It Contains

- Bilingual routes: `/ch/` and `/en/`
- Personal brand homepage
- GitHub project portfolio
- AI Skills directory with Skillhub and Clawhub links
- Project cases
- Blog and build notes
- Internal styleguide and maintenance docs

## Local Preview

Use Hugo Extended:

```powershell
hugo server
```

This workspace also keeps a portable Hugo binary under `.tools/` for local checks, but `.tools/` is not committed.

## Maintenance Principles

- High cohesion, low coupling
- Extensible and easy to maintain
- Efficient and simple
- Do not add complexity unless it is needed

- `docs/content-maintenance-guide.md`
- `docs/agent-update-guide.md`
